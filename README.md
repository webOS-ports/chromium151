# chromium151
Chromium 151 build based upon LG webOS OSE's Chromium 120 build

Find more information about open source Chromium in Google's [The Chromium Project](http://www.chromium.org/developers/design-documents/) page.

## How to Build
This repository will be built within OE(Open Embedded) build system of LuneOS platform.
